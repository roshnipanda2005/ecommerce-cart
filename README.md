# 🛒 Flipkart-style E-Commerce Cart

A responsive Flipkart-inspired e-commerce cart application built using HTML, CSS, and JavaScript.  
This project demonstrates core front-end development skills such as DOM manipulation, cart logic, and local storage usage.

---

## 📌 Project Description

The E-Commerce Cart allows users to browse products, add them to a cart, update quantities, and view the total price dynamically.  
Cart data is stored using browser localStorage, ensuring persistence even after page refresh.

This project was built as part of my internship preparation to gain hands-on experience in real-world web development.

---

## ✨ Features

- Product listing interface
- Add to cart functionality
- Increase / decrease product quantity
- Remove items from cart
- Dynamic total price calculation
- Cart data persistence using localStorage
- Responsive and clean UI
